# Collector error codes

These are the values of collector_outcome.error_code. Each one names why pg-probe did not collect a source, and the status column says how bad it is. os_error_code holds the Linux errno when the failed call reported one, and is NULL otherwise. The artifact keeps no free-text error message on purpose, so it never stores sensitive text such as connection settings or server messages.

- `activity_aggregates_failed`: The pg_stat_activity aggregate query for postgres.aggregates.activity failed. A query_failed row for the same source comes first. postgres_activity_aggregates has no rows for that sample. Status: io_error.
- `archiver_stats_failed`: The pg_stat_archiver query for postgres.stats.archiver returned a row, but archived_count or failed_count did not parse as an integer. A failed query does not give this code: it gives query_failed and then a collected row with no data. Status: io_error.
- `authentication_failed`: The server refused the connection with a SQLSTATE in class 28 (invalid authorization specification). PostgreSQL uses this class for a wrong password and for a connection that pg_hba.conf rejects, and the code does not tell them apart. The source is postgres.connection, or postgres.extensions.visit for a per-database connection. Status: io_error.
- `bgwriter_stats_failed`: The pg_stat_bgwriter query for postgres.stats.bgwriter failed. A query_failed row for the same source comes first. postgres_bgwriter_stats has no row for that sample. Status: io_error.
- `block_device_read_failed`: pg-probe listed /sys/block, but reading the next directory entry failed with an error other than not found before any device was recorded. Source sys.block.devices. A device whose dev file cannot be read is skipped without an outcome. Status: io_error.
- `cgroup_events_not_available`: pg-probe found no cgroup event counter for source proc.cgroup.events. On cgroup v2, none of cpu.stat, memory.events and pids.events in the process cgroup gave a value. On cgroup v1, the cpu controller path was not found or cpuacct.usage did not give a value. The code does not tell a missing file from an unreadable one. Status: unsupported.
- `cgroup_io_empty`: pg-probe read the cgroup I/O file for source proc.cgroup.io (io.stat on v2, blkio.io_service_bytes_recursive on v1), but it held no line with a valid major:minor device. Status: unsupported.
- `cgroup_io_not_available`: pg-probe found no path to the cgroup I/O file for source proc.cgroup.io. On cgroup v2, the process cgroup path was not resolved. On cgroup v1, no blkio controller is mounted for the process cgroup. Status: unsupported.
- `cgroup_io_read_failed`: pg-probe could not read the cgroup I/O file (io.stat on v2, blkio.io_service_bytes_recursive on v1) for source proc.cgroup.io. Unsupported when the file does not exist, permission_denied when access is refused, io_error otherwise, including a file over 1 MiB, which has no os_error_code. Status: unsupported, permission_denied or io_error.
- `cgroup_v2_path_unresolved`: /proc/self/mountinfo shows a cgroup2 mount, but pg-probe could not resolve the process cgroup path, because a second read of /proc/self/mountinfo or the read of /proc/self/cgroup failed. Source proc.cgroup. linux_cgroup has no row. Status: unsupported.
- `checkpointer_stats_failed`: The pg_stat_checkpointer query for postgres.stats.checkpointer failed. A query_failed row for the same source comes first. postgres_checkpointer_stats has no row for that sample. Status: io_error.
- `collector_panicked`: A collector panicked. pg-probe dropped all of its observations for that run and wrote this one row. The source is the name of the collector, such as linux.memory or postgres, or postgres.stats when the panic happened inside the PostgreSQL statistics collection. Status: io_error.
- `connected_user_invalid`: current_user contains characters that pg-probe does not allow in an identifier, so pg-probe did not store it. Source postgres.target.identity. A target_failed row follows. Status: parse_error.
- `connection_failed`: A connection attempt failed with a server error outside SQLSTATE classes 28 and 3D, or with no server error at all, such as a network, socket or TLS failure. os_error_code holds the errno when the driver reports an OS error. The code does not keep the message, so the causes look the same in the artifact. The source is postgres.connection, or postgres.extensions.visit for a per-database connection. Status: io_error.
- `cpu_online_unavailable`: pg-probe skipped source sys.cpu.topology because source sys.cpu.online was not collected in the same run. The sys.cpu.online row shows why. Status: unsupported.
- `cpu_set_read_failed`: pg-probe could not read /sys/devices/system/cpu/online, present or possible for source sys.cpu.online, sys.cpu.present or sys.cpu.possible. Unsupported when the file does not exist, permission_denied when access is refused, io_error otherwise, including a file over 1 MiB, which has no os_error_code. linux_cpu_set has no rows for that set. Status: unsupported, permission_denied or io_error.
- `cpus_allowed_list_not_found`: /proc/self/status has no Cpus_allowed_list line. Source sched.cpu.affinity. linux_cpu_set has no affinity rows. Status: parse_error.
- `database_does_not_exist`: The server refused the connection with a SQLSTATE in class 3D (invalid catalog name), which PostgreSQL returns when the database does not exist. The source is postgres.connection, or postgres.extensions.visit for a per-database connection. Status: io_error.
- `database_name_invalid`: A pg_database.datname contains characters that pg-probe does not allow in an identifier. Source postgres.databases.inventory, one row per such database. pg-probe keeps the database in postgres_database with database_name '<invalid>'. Status: parse_error.
- `database_not_connectable`: pg-probe skipped the per-database visit on purpose, because the database is a template or does not allow connections (can_connect = allows_connections and not is_template). pg-probe does not try to connect, so no connection error is involved. Source postgres.extensions.visit, one row per skipped database. postgres_database.is_template and allows_connections show which case, and extension_visit_status is not_connectable. Status: unsupported.
- `database_stats_failed`: The pg_stat_database query for postgres.stats.database failed. A query_failed row for the same source comes first. postgres_database_stats has no rows for that sample. Status: io_error.
- `databases_failed`: pg-probe could not build the database inventory for source postgres.databases. The pg_database query failed (a query_failed row for postgres.databases.inventory comes first) or a datname, datistemplate or datallowconn value did not parse. postgres_database has no rows. Status: parse_error.
- `datname_invalid`: pg-probe did not connect to a database for its visit, because the name failed the identifier check. This happens for a database stored as '<invalid>' in postgres_database. Source postgres.extensions.visit. An extension_visit_failed row follows. Status: parse_error.
- `diskstats_read_failed`: pg-probe could not read /proc/diskstats for source proc.diskstats. Unsupported when the file does not exist, permission_denied when access is refused, io_error otherwise, including a file over 1 MiB, which has no os_error_code. linux_block_io has no rows for that sample. Status: unsupported, permission_denied or io_error.
- `extension_visit_failed`: The visit to one database failed. Source postgres.extensions.visit. The connection failed (an earlier postgres.extensions.visit row has the connection code), the pg_extension query failed (a query_failed row for postgres.extensions), the name failed the check (datname_invalid), or a value did not parse. postgres_database.extension_visit_status is permission_denied when the pg_extension query failed and connection_failed otherwise. The code does not check privileges, so permission_denied there only means the query failed. Status: io_error.
- `getrlimit_failed`: getrlimit(2) failed for every resource limit pg-probe reads. Source proc.rlimit. When only some calls fail, those limits are missing from linux_resource_limit and the source is collected. Status: io_error.
- `in_recovery`: The WAL position query for postgres.stats.wal_position returned NULL. The query returns NULL when pg_is_in_recovery() is true, so the server is a standby. postgres_target.in_recovery shows the same. Status: unsupported.
- `initial_database_invalid`: current_database() contains characters that pg-probe does not allow in an identifier, so pg-probe did not store it. Source postgres.target.identity. A target_failed row follows. Status: parse_error.
- `invalid_cpu_id`: A single CPU number in a CPU list is not an unsigned integer. The source is sys.cpu.online, sys.cpu.present, sys.cpu.possible or sched.cpu.affinity (Cpus_allowed_list in /proc/self/status). Status: parse_error.
- `invalid_cpu_range_end`: The end of a CPU range such as 0-7 in a CPU list is not an unsigned integer. The source is sys.cpu.online, sys.cpu.present, sys.cpu.possible or sched.cpu.affinity (Cpus_allowed_list in /proc/self/status). Status: parse_error.
- `invalid_cpu_range_order`: A CPU range in a CPU list starts after it ends. The source is sys.cpu.online, sys.cpu.present, sys.cpu.possible or sched.cpu.affinity (Cpus_allowed_list in /proc/self/status). Status: parse_error.
- `invalid_cpu_range_start`: The start of a CPU range such as 0-7 in a CPU list is not an unsigned integer. The source is sys.cpu.online, sys.cpu.present, sys.cpu.possible or sched.cpu.affinity (Cpus_allowed_list in /proc/self/status). Status: parse_error.
- `invalid_cpu_time_line`: A line in /proc/stat that starts with cpu has a CPU number that does not parse, fewer than 8 fields, or a user, nice, system or idle value that is not a number. Source proc.stat.cpu. linux_cpu_time has no rows for that sample. Status: parse_error.
- `invalid_diskstats_major`: In /proc/diskstats, on a line with at least 14 fields,, the major device number (field 1) is not an unsigned integer. Source proc.diskstats. linux_block_io has no rows for that sample. Status: parse_error.
- `invalid_diskstats_minor`: In /proc/diskstats, on a line with at least 14 fields,, the minor device number (field 2) is not an unsigned integer. Source proc.diskstats. linux_block_io has no rows for that sample. Status: parse_error.
- `invalid_interface_name`: An interface name in /proc/net/dev is empty, longer than 15 bytes, or has a character that is not printable ASCII. Source proc.net.dev. The whole source fails, so linux_network_io has no rows for that sample. Status: parse_error.
- `invalid_io_in_progress`: In /proc/diskstats, on a line with at least 14 fields,, I/Os in progress (field 12) is not an unsigned integer. Source proc.diskstats. linux_block_io has no rows for that sample. Status: parse_error.
- `invalid_io_ms`: In /proc/diskstats, on a line with at least 14 fields,, time spent doing I/O (field 13) is not an unsigned integer. Source proc.diskstats. linux_block_io has no rows for that sample. Status: parse_error.
- `invalid_loadavg`: /proc/loadavg has fewer than 4 fields, a load average that is not a number, or a fourth field that is not running/total task counts. Source proc.loadavg. Status: parse_error.
- `invalid_meminfo_value`: In /proc/meminfo, the value of a key pg-probe keeps is not an unsigned integer. Source proc.meminfo. linux_memory has no rows for that sample. Status: parse_error.
- `invalid_mount_device`: In /proc/self/mountinfo, on a line with at least 10 fields, the third field is not a major:minor device number. Source proc.mounts. linux_mount has no rows. Status: parse_error.
- `invalid_mount_id`: In /proc/self/mountinfo, on a line with at least 10 fields,, the mount ID (field 1) is not an unsigned integer. Source proc.mounts. linux_mount has no rows. Status: parse_error.
- `invalid_mountinfo_format`: In /proc/self/mountinfo, the '-' separator is the last field of a line, so the filesystem type is missing. Source proc.mounts. linux_mount has no rows. Status: parse_error.
- `invalid_net_dev_counter`: In /proc/net/dev, a counter of an interface that pg-probe keeps is not an unsigned integer. Source proc.net.dev. linux_network_io has no rows for that sample. Status: parse_error.
- `invalid_net_dev_format`: An interface line in /proc/net/dev has fewer than 16 counters. Source proc.net.dev. linux_network_io has no rows for that sample. Status: parse_error.
- `invalid_numa_cpulist`: /sys/devices/system/node/nodeN/cpulist for an online node is not a valid CPU list. Source sys.numa.topology. linux_numa_node has no rows. Status: parse_error.
- `invalid_numa_online`: /sys/devices/system/node/online is not a valid node list. Source sys.numa.topology. linux_numa_node has no rows. Status: parse_error.
- `invalid_os_release_escape`: A quoted ID, VERSION_ID or PRETTY_NAME value in the os-release file ends with a lone backslash. Source linux.os_release. The distribution columns of linux_identity are NULL. Status: parse_error.
- `invalid_os_release_quote`: An ID, VERSION_ID or PRETTY_NAME value in the os-release file starts with a quote but does not end with the same quote. Source linux.os_release. The distribution columns of linux_identity are NULL. Status: parse_error.
- `invalid_parameter`: pg-probe could not build the connection settings, so it did not try to connect. The code gives this code when --dbname is empty or holds a NUL byte, when a conninfo string or URI in --dbname does not parse, or when PGSSLMODE has a value pg-probe does not accept. Source postgres.connection. Status: parse_error.
- `invalid_parent_mount_id`: In /proc/self/mountinfo, on a line with at least 10 fields,, the parent mount ID (field 2) is not an unsigned integer. Source proc.mounts. linux_mount has no rows. Status: parse_error.
- `invalid_psi_avg_value`: An avg10, avg60 or avg300 value in /proc/pressure/cpu, memory or io is not a number. The source is proc.pressure.cpu, proc.pressure.memory or proc.pressure.io. linux_psi has no rows for that resource in that sample. Status: parse_error.
- `invalid_psi_line`: A some or full line in /proc/pressure/cpu, memory or io has no values after the scope. The source is proc.pressure.cpu, proc.pressure.memory or proc.pressure.io. linux_psi has no rows for that resource in that sample. Status: parse_error.
- `invalid_psi_total_value`: A total value in /proc/pressure/cpu, memory or io is not an unsigned integer. The source is proc.pressure.cpu, proc.pressure.memory or proc.pressure.io. linux_psi has no rows for that resource in that sample. Status: parse_error.
- `invalid_read_ms`: In /proc/diskstats, on a line with at least 14 fields,, time spent reading (field 7) is not an unsigned integer. Source proc.diskstats. linux_block_io has no rows for that sample. Status: parse_error.
- `invalid_reads_completed`: In /proc/diskstats, on a line with at least 14 fields,, reads completed (field 4) is not an unsigned integer. Source proc.diskstats. linux_block_io has no rows for that sample. Status: parse_error.
- `invalid_reads_merged`: In /proc/diskstats, on a line with at least 14 fields,, reads merged (field 5) is not an unsigned integer. Source proc.diskstats. linux_block_io has no rows for that sample. Status: parse_error.

- `invalid_sectors_written`: In /proc/diskstats, on a line with at least 14 fields,, sectors written (field 10) is not an unsigned integer. Source proc.diskstats. linux_block_io has no rows for that sample. Status: parse_error.
- `invalid_uname_machine`: The machine field returned by uname(2) is not valid UTF-8. Source linux.uname. hostname and the kernel columns of linux_identity are NULL. Status: parse_error.
- `invalid_uname_nodename`: The nodename field returned by uname(2) is not valid UTF-8. Source linux.uname. hostname and the kernel columns of linux_identity are NULL. Status: parse_error.
